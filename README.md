# React Album

A photo browsing interface built with React and TypeScript. The application separates navigation, photo cards, individual photo views, loading states, and API requests into dedicated modules.

I used this project to practice building a multi-view React application, organizing components, handling asynchronous requests, and defining typed data for the UI.

## Features

- Photo browsing interface
- Individual photo/detail view
- Navigation with React Router
- Loading state components
- Dedicated API request module
- Responsive styling with Tailwind CSS

## Tech stack

- React 18
- TypeScript
- Vite
- React Router
- Axios
- Tailwind CSS
- React Icons

## Run locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
